# Chromatic Run: Temple of Colours

## About the Game
An endless runner exploring color theory through gameplay.

## Features
- Color-changing gates and obstacles
- Color theory challenges
- Collectibles and scoring
- Game-over and restart system

## Controls
- A / D or Arrow Keys: Move
- Space: Jump
- R: Restart
